# Contributing

This repository is a Proof of Concept for community experimentation around ZKGRM mining. It may contain bugs, incomplete checks, or platform-specific assumptions.

Contributions are welcome for the benefit of the whole community.

## Good Contributions

- Bug fixes with clear reproduction steps.
- Safer wallet handling and better defaults.
- Tests for PoW body generation and transaction sending.
- Linux, macOS, and Windows setup notes.
- Documentation improvements in English or Russian.

## Pull Request Checklist

- Explain what changed and why.
- Mention how you tested it.
- Do not commit private keys, mnemonics, `.env`, mined BOCs, or wallet dumps.
- Keep changes small and focused when possible.

## Security

Report security issues privately first if they can lead to loss of funds. For normal bugs, open an issue or PR.
